Adicionando Estilos com CSS

Chamadas CSS (seletores)

Existem diversas formas de chamar tags HTML no CSS. Os seletores CSS mais tradicionais são: chamar pela class, ID, nome da tag e hierarquia de tags.

Como escrever CSS - Vínculos

Há 3 formas de vincular o CSS a uma tag ou página HTML. Podemos criar um arquivo externo de CSS, adicionar o CSS direto no HTML através da tag style ou adicionar o estilo usando o atributo tag style.
